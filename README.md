## Why Checkpoint?

Most game trackers treat every game like it has an ending. But you never really "finish" Valorant, League or Overwatch. Checkpoint splits your games into two kinds:

| 📚 **Library** | ⚔️ **PvP** |
|---|---|
| Games you can finish | Competitive & live-service games |
| Backlog → Playing → Completed | Main game, Casual, On a break, Retired |
| Completion checklists with progress bars | Current rank, peak rank and your main |

## Features

- **🎮 Game search with auto-fill.** Type a game, pick it from the list, and Checkpoint grabs its banner, release year and genres.
- **✅ Completion checklists.** Track bosses, collectibles and achievements for every game. Paste a whole list at once.
- **⚔️ A real PvP section.** No "completed" button for games that never end.
- **🎬 Clips.** Add YouTube, Twitch or Streamable links and watch them right in the app.
- **👤 Customizable profile.** Banner, profile picture, bio, gamer tags, favorite games and sections you can turn on, off and reorder.
- **🎨 Make it yours.** 9 theme presets, custom colors, fonts, background effects, corner roundness and card size.
- **🔒 Private by default.** No sign-up. Everything is saved in your own browser.
- **💾 Backups.** Export and import your data any time.
- **📱 Works on phones.**

## How to use it

1. Open the [live site](https://YOURNAME.github.io/checkpoint/).
2. Click **+ Add game** and start typing a title.
3. Click any game to add checklist items, ranks, clips and notes.
4. Make it yours on the **Customize** and **Profile** tabs.

> **Tip:** Your data lives in your browser. Use **Customize → Export backup** now and then so you never lose it.

## Run it yourself

Checkpoint is a single `index.html` file with no build step.

1. Download `index.html` and open it in your browser.
2. *(Optional)* To turn on game search, get a free key at [rawg.io/apidocs](https://rawg.io/apidocs) and paste it into `RAWG_KEY` near the top of the script.
